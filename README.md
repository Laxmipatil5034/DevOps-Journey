# DevOps Server Health & Error Handling Automation

## 📌 About

This is a beginner DevOps automation project created using Bash Shell Scripting.

The project checks the health of a Linux server before deployment and handles errors when something is not working correctly.

## 🛠️ Technologies Used

- Linux
- Bash Shell Scripting
- Git
- Docker
- Nginx
- AWS EC2

## 🔍 Health Checks

The script checks:

1. Git installation
2. Docker installation
3. Docker access
4. Nginx installation
5. Nginx service status
6. Disk usage
7. Memory usage

## 🚨 Error Handling

The script demonstrates:

- if / else
- Functions
- Exit codes
- Command checking
- Service checking
- Error counting
- Error messages
- Log generation
