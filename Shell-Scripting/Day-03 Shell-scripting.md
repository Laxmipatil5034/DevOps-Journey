# Day 03 - DevOps Server Health & Error Handling

## 📖 Overview

On Day 03 of my #90DaysOfDevOps journey, I built a Bash Shell Script to automate Linux server health checks before deployment.

The script verifies essential DevOps tools and system resources while generating a log file for troubleshooting.

## 🚀 Features

- Check Git installation
- Check Docker installation
- Verify Docker access
- Check Nginx installation
- Verify Nginx service status
- Monitor Disk Usage
- Monitor Memory Usage
- Generate health_check.log
- Error Handling using Bash

## 🛠️ Technologies

- Linux
- Bash Shell
- Git
- Docker
- Nginx
- AWS EC2
